# QRCodeExtension working rules

Resume work in this order: `docs/NOW.md` → feature `SPEC.md` / `STATE.md` → task `GOAL.md` / `CHECKLIST.md` → code and tests.

Keep `OTHER.md`, `PLAN.md`, `NOW.md`, and `DONE.md` mutually exclusive for active work: move an item through `OTHER → PLAN → NOW → DONE` exactly once. Update `NOW.md` in the same turn for follow-ups, phase changes, result changes, and before each ten-minute uninterrupted-work boundary.

Project documents are local-only working memory. Conversation context is not a source of truth.

Each feature needs `REQUEST.md`, `SPEC.md`, and `STATE.md`. Each durable task needs `GOAL.md` and `CHECKLIST.md`. Record explicit Plan, Do, Check, and Act evidence. UI changes also require the UI state matrix and review rubric to be checked.
